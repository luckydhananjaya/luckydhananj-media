# luckydhananj-media

Public media host for [@luckydhananj](https://www.instagram.com/luckydhananj/) Instagram and Threads autopost.

The Graph API can only fetch media from a public URL, so images and videos will live here and be served by GitHub Pages:

**https://luckydhananjaya.github.io/luckydhananj-media/**

The publisher itself is in the private repo `luckydhananjaya/luckydhananj-autopost`. This repo has no tokens, no queue, and no captions.

Media for the current queue (m_m06, m_m11, m_m07, m_m12, m_m13, m_m14, m_m15, m_m16, m_m17, m_m18, r5, pt_south_jakarta) is in the repo root.
